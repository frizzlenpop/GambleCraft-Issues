# GambleCraft bug reports

This is the public bug tracker for **GambleCraft**, a Minecraft mod designed for content creators. Stake in-game items at an Upgrade Station for a chance to upgrade them, with animated rolls, nearby spectators, and server-wide big-win announcements.

- [Download GambleCraft on Modrinth](https://modrinth.com/project/gamblecraft)
- [Report a bug](https://github.com/frizzlenpop/GambleCraft-Issues/issues/new?template=bug_report.yml)
- [Search existing reports](https://github.com/frizzlenpop/GambleCraft-Issues/issues)

## Reporting a problem

Please include your GambleCraft version, Minecraft version, mod loader and loader version, the steps to reproduce the problem, and what you expected to happen. Attach relevant logs or crash reports and, when useful, a screenshot or short clip. Remove private information before sharing logs.

For multiplayer issues, explain whether the problem affects the server, the player using the station, or spectators. For recording and streaming issues, describe your creator setup.

GambleCraft must be installed on the server and on each player's client, using the matching Minecraft and loader build.

## About this repository

This repository contains the public issue tracker and support information. The GambleCraft source code is maintained separately.
